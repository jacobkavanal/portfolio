## What Was Implemented (per spec)

### Step 1: Slider + filtering
- `commitProgress`, `timeScale`, `commitMaxTime`, `filteredCommits` module-level vars
- `timeScale = d3.scaleTime().domain([min, max]).range([0, 100])`
- Range input `id="commit-progress"`, `<time id="commit-time">` in a flex label
- `onTimeSliderChange()` updates time display, filters commits, calls `updateScatterPlot` + `updateFileDisplay`
- `updateScatterPlot()` selects existing SVG, updates xScale, clears/redraws `.x-axis`, uses key fn `.data(sortedCommits, d => d.id)`
- `@starting-style { circle { r: 0; } }` in CSS for entry animation

### Step 2: Unit visualization
- `updateFileDisplay()` extracts lines from filtered commits, groups by file, sorts descending by line count
- D3 join creates `<div><dt><code>filename</code></dt><dd>…dots…</dd></div>` structure
- 794 `.loc` dots rendered as small circles, colored by file type via `--color` CSS variable and `d3.schemeTableau10`
- CSS grid with subgrid for alignment; `#files dd` uses flex-wrap

### Step 3: Scrollytelling
- Scrollama imported from `https://cdn.jsdelivr.net/npm/scrollama/+esm` (version-pinned `@3.2.0` returns 400 from jsDelivr — use unpinned)
- `.step` divs generated for each commit with date, short id (linked), and line count
- `onStepEnter` uses `response.element.__data__.datetime` to filter and update both scatter + files
- `scroller.setup({ container: '#scrolly-1', step: '#scrolly-1 .step' })`

## What Didn't Work / Decisions Made
- **`scrollama@3.2.0/+esm` → 400**: jsDelivr's ESM endpoint returns 400 for this specific pinned version. Fix: use `scrollama/+esm` (unpinned).
- **Brush/selection removed**: The brush selector, selection count, and language breakdown from earlier labs were removed at user request (scrollytelling replaces that interaction).
- **Step 4 (optional)**: Skipped per user request.
- **Scrollytelling layout**: Initially tried side-by-side flex (spec default), then switched to vertical — files above, sticky chart, text story below. Sticky chart needs `z-index: 1; background: canvas` to prevent story text from painting over it on scroll.
- **`meta.js` vs `main.js`**: Spec says `meta.js`; project had `main.js`. Renamed to `meta.js`, deleted `main.js`.
